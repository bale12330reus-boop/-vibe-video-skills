# 暗房灯串 · 哲学感知识短片：输入主题 → 成片

- 画面怎么画：`references/风格-暗房灯串.md`（**先读**，里面有引擎还没做完的清单）+ `references/原片截图/`
- 已经做成的一条：`examples/情绪内耗/`（文案、分镜、投稿文案、三个场景文件），拿不准就照着抄结构
- 引擎和模板：`assets/`；脚本：`scripts/`

## 你从用户那里拿什么

- **必填**：主题。
- **可选**：时长（默认跟 BGM 走，约 2.5 分钟）；章节名（左上角，默认就是主题）；要不要分步确认（默认在样片处停一次）。
- **BGM**：在项目文件夹或用户说的位置找音频，复制成 `<主题>-skill版/bgm.mp3`。多个就问；**没有就停下来问**，不要自己生成或下载。（例：你电脑里以前用过、节奏偏快的那首，沿用时提醒用户确认节奏是否合适。）
- **口播**：原片和《情绪内耗》都没有口播，默认不做。用户要的话，参考 `vibe-particle-essay` 的口播段。

## 文件夹

产物放进新建的 `<项目根>/<主题>-skill版/`，**绝不写进已经存在的同名旧文件夹**。

```
<主题>-skill版/
  bgm.mp3  文章.md  文案.md  意象.md  分镜.md  投稿文案.md
  video/      index.html（由 assets/index-模板.html 改）  engine.js  scenes-a/b/c.js  cover.html
              assets/ gsap.min.js grain.png bgm.mp3 fonts/NotoSerifSC-VF.ttf
              snapshots/  renders/
  sample/     index.html（由 assets/sample-模板.html 改名）  sample.js  + 和 video/ 一样的 js 与 assets
  封面/封面-3x4.png
```

**复制文件后必须核对**：`Copy-Item` 会静默失败。每次把改过的 js 复制到 video/ 或 sample/ 后，用 `Select-String` 查一个这次新加的特征字符串，确认目标文件里真有新代码，再截图或渲染。

## 第 1 步 · 搜集 → 文章.md

```
<role>你是知识科普作者，最在意事实准确。</role>
<task>上网搜【主题】，按这条线整理：
① 过去人们怎么理解/应对它（旧认识、老话、传统）；
② 旧认识怎么被推翻或证明不管用（哪一年、谁、什么研究）；
③ 新的理解能拆成哪三步，每步一个能画出来的意象；
④ 它跟普通人日常的哪件小事有关。存成 文章.md。</task>
<check>年份、人名、数字、原话都要有权威出处，链接写在每段后面。名人原话查到原始出处，只有转载的删掉。找不到可靠出处的一律删，文末列出删了什么、全部出处。研究结论有争议的（比如重复验证失败），文案里要说得保守。</check>
```

## 第 2 步 · 文案 → 文案.md（六段结构）

```
<role>你是哲学感知识短片的编剧：语气沉静、有点扎心，最后是温暖的。</role>
<task>把 文章.md 改成一幕一句的文案，约 30–33 幕：
1. 开头：一个扎心的问题，第 0 帧就在屏幕上（"想了一整夜，然后呢？""努力之后呢？"）；
2. 过去：人们原来靠什么；
3. 倒塌：旧认识被推翻，人一下没了方向（这里放那一幕亮灰反差）；
4. 三步：每步一个具体意象（骆驼/狮子/孩子；看见念头/让白熊坐下/先动起来），每步一个关键字大字；
5. 反转：原以为是坏事，其实是自由 / 原以为要先想通，其实先走就通了；
6. 结尾：落到身边的小事（一碗汤、早餐铺的热气），最后一句跟开头的问题首尾呼应。
每幕后面括号写一个画面主角，另标出这一幕的字幕重点词。</task>
<avoid>一屏超过 20 个字；文章.md 里没有的事；说教、鸡汤感叹；"你应该"式建议清单。</avoid>
<check>诚实打分（满分 10）并写缺点：有没有一句让人想转发、想争论的刺耳观点？三步是不是像在上课？不要自夸。</check>
```

## 第 3 步 · 意象 → 意象.md

每幕写：主角是什么、几根线能画出来、怎么出现（粒子聚合 / 一笔笔点亮 / 碎片拼起）、怎么消失（碎裂 / 散成粒子 / 淡出）、有没有关键字大字或点阵字。全片挑 2–3 个反复出现的线索意象（原片"地平线"；情绪内耗"线团 → 地平线"、白熊），开头结尾都要出现。至少一幕用一排小人表示"所有人"。

## 第 4 步 · 读拍子 → 分镜.md

`python scripts/beat.py <主题>-skill版/bgm.mp3`（需要 `pip install numpy miniaudio`），拿到 `bpm`、`first_downbeat`、小节起点、每 2 秒响度。每幕 6–10 拍（约 4–5 秒），切点都落在拍子上；BGM 有多长片子就多长，不够就压短每幕，不删幕。分镜每个镜头写：起止拍、画面、字幕、重点词、动法。

## 第 5 步 · 写页面

1. 把 `assets/` 下的 engine.js、gsap.min.js、grain.png、fonts/ 复制到 video/assets 和 video/，bgm.mp3 放进 video/assets/。
2. **先补引擎**：按 `references/风格-暗房灯串.md` 第 8 节，把"没做"的几项补进 engine.js（角标、波浪流线、关键字大字、字幕重点词、亮灰反差、太阳放射线、小人 s=1.45、走路轮廓）。每补一项用 snap.ps1 截一张，和原片截图并排看。补好后**把新 engine.js 复制回本 skill 的 assets/，并更新那张表**。
3. 改 engine.js 顶部这几处（只有这里跟具体片子有关）：
   - `BEAT = 60 / <bpm>`，`B0 = <first_downbeat>`
   - `SB = [...]`：每一幕从第几拍开始，最后一个数是片尾
   - 线团 `TANG`、白熊 `BEAR_*` 是情绪内耗专用的，新主题不用就删掉，换成自己的意象
4. 场景照 `examples/情绪内耗/scenes/` 的写法，分成 scenes-a/b/c.js（单个文件太长容易写坏）。常用接口：
   - `paint(t0, t1, (c, lt, t) => {...}, z)` 注册一段画面，只按时间画
   - `DD(c, dotPath(点列表), { p: 画到几成, m: 聚合进度, q: 碎裂进度, a: 透明度, t })`
   - `drawFig(c, POSE.stand 或 walkPose(相位), x, 脚底y, s, { p, a, t })`
   - `textAt(key, "字", 字号, x, y, 点距, seed)` 点阵字
   - `say({ t0, t1, text })` 字幕；`T(n)` 第 n 幕开始的秒数
   - scenes-c.js 末尾的"注册"段原样保留（用属性 setter 驱动时钟：HyperFrames 渲染时 seek 会屏蔽 onUpdate，canvas 靠它每帧重画；先 `totalTime(.01)` 再跳目标时间强制重绘）
5. index.html 由 `assets/index-模板.html` 改：标题、`data-duration`（= END）、BGM 的 `data-duration`。
6. 预览某一刻：`index.html?t=秒数`。

## 第 6 步 · 截图核对

先 `resource_status`：内存紧张就只截几张，别渲染。
`powershell -File scripts/snap.ps1 -VideoDir <...>\video -Items "index.html?t=1|1,index.html?t=40|40,..."`，每段挑一帧，再 `scripts/sheet.ps1` 拼成对照图，和 `references/原片截图/` 对比：
- 背景纯黑，除结尾外没有颜色；线是灯串珠不是实线/虚线；小人是外轮廓剪影、约 220px 高；
- 字幕底部居中、不出框不重叠、重点词加粗；左上右上角标都在；关键字大字发光；
- 有波浪流线；画面每一帧在动；没有东西被挡住。
不合格就改，改完重新复制、核对、再截。

## 第 7 步 · 10 秒样片（停一次给用户看）

挑最能代表风格的一段（有小人、有主意象、有关键字），在 sample/ 里改 `sample.js` 的 `S0 = T(幕号)`，BGM 剪一段 10 秒存成 `assets/bgm-sample.mp3`。
渲染：`powershell -File scripts/render.ps1 -VideoDir <...>\sample -Out renders\<主题>-样片.mp4`
（独立进程，不会被命令结束连带杀掉；版本固定 hyperframes@0.8.143、`--yes` 自动确认；默认 1 worker + 低内存模式）。看 `render.log` 出现 EXIT 0 再取片，抽几帧核对，然后发给用户，**等用户说"风格可以"再做整片**。

## 第 8 步 · 整片

`powershell -File scripts/render.ps1 -VideoDir <...>\video -Out renders\<主题>-整片.mp4`，约 6 分钟（2.5 分钟片）。完成后用 ffprobe 读分辨率/时长/有无音轨，抽 8 帧核对。下载区上限 50MB，整片超了就告诉用户文件路径。

## 第 9 步 · 投稿文案 + 竖版封面

- **投稿文案.md**：3 个标题（推荐和片头那句一致的）、简介（心理类主题附一句"难受很久的话，记得找专业的人聊聊"）、标签、资料出处、BGM 曲名（不知道就留空让用户填）。格式见 `examples/情绪内耗/投稿文案.md`。
- **竖版封面 1080×1440**：由 `assets/cover-模板.html` 改，用片子里最好认的一个画面（人 + 主意象），大标题 = 片头那句，顶部小字"VIBE 知识大赏 · <主题>"。用 snap.ps1 加 `-Width 1080 -Height 1440` 截图存成 `封面/封面-3x4.png`。横版封面用户要再做。

## 交付

成片 + 投稿文案 + 竖版封面三样齐了才算完。汇报时说清：做了哪些核对、哪些没逐秒看过、配乐合不合适要用户听了才知道。
