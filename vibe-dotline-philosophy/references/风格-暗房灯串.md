# 风格：暗房灯串（逆向自《虚无主义》尼采片）

原片截图在 `references/原片截图/`（o83 骆驼→狮子、o94、o114 "好"、o146）。拿不准就打开截图对着看，别凭印象。
下面的坐标都按 1920×1080 写。

## 1. 底子

- 背景纯黑 `#000`。四周压暗角，叠一层很淡的颗粒（`grain.png`，soft-light，约 22%）。
- 全画面飘几十颗很暗的微光尘，一直在慢慢漂，每一帧都在动。
- 全片只有黑白灰。**唯一的颜色**是结尾日出的暖黄光，只出现一次。
- 中间安排**一次**亮灰背景的反差幕（原片：1882 年尼采喊出"上帝死了"那一幕，灰底黑剪影）。放在"倒塌"那一段最重的一句上。

## 2. 线条 = 灯串（最重要，之前理解错过）

不是虚线，不是点阵，是**一串小灯珠**：
- 珠子半径约 2–2.9px，比较亮（不透明度 .88–1），珠子之间留空，间距约 11px。
- 珠子之间连一根 1px 的细线，约 30% 透明度——远看像节日挂的灯串。
- 整幅线稿外面有一层柔光（画布复制一份，模糊 7px，叠在下面）。
- 画出来的方式：一笔一笔沿着线"点亮"，笔尖那颗珠子更大更亮。

## 3. 小人和物件 = 外轮廓剪影

- 小人是**一整条外轮廓**勾出来的：圆头（半径约 20）+ 有宽度的身子、胳膊、腿，像厕所门牌上的小人。不是火柴人，不是豆子人。
- 原片小人高约 220px：引擎里小人原始高度 152，`drawFig(..., s)` 的 `s` 用 **1.45 左右**。
- 动物、建筑也一样只画外轮廓：狮子、骆驼、城堡、拱门、书。
- "所有人"用**一排小人**表示，不要总是只有一个人。
- 小人有动作就有情绪：伸手、低头、走、坐、抱膝。每一幕至少一个明确的姿势。

## 4. 背景细波浪流线

- 很多场景里横贯画面有 4–8 条**很细的长波浪线**（1px、15–25% 透明度），缓慢地左右流动，像沙丘或水面。地面附近更密，往上越来越稀。
- 有时换成几圈扁扁的**椭圆轨道**环绕在地面上（"好"那幕），地面下方撒一片散落的亮点。
- 这些线是氛围，不能抢主体：比灯串暗很多，没有珠子。

## 5. 文字

| 用途 | 样子 |
|---|---|
| 字幕 | 底部居中，基线约 y=990，约 40px 宋体，偏灰白 `rgba(255,255,255,.8)`，字距宽。**重点词加粗、纯白**（原片："狮子""孩子""答案""好"） |
| 关键字大字 | 白色**实心**粗宋体（800–900），约 170px，外面一圈白色发光（text-shadow），悬在主体正上方居中。一幕最多一个字/词（"好""我不"） |
| 点阵字 | 词本身被做成灯串点阵，漂浮、倾斜、散落、组成东西（"按部就班"压在骆驼头上；"你应该"组成龙） |
| 片头钩子、片尾一句 | 居中放大，由点阵聚合出现，再散成粒子 |
| 左上角标 | 章节名，白色粗宋体约 34px，字上下各一根细横线（x≈73–226，y≈49–98） |
| 右上角标 | 一个 1px 灰描边小方框，里面灰色细宋体约 24px，字距很大（x≈1710–1855，y≈49–87）。写栏目名，**用"Vibe知识大赏"，不抄原片的"叁号暗房"** |

除了开头和结尾那两句，**不要**把整句字堆在画面正中。

## 6. 动法

粒子聚合成形 / 线条一笔笔点亮 / 碎裂四散 / 镜头缓慢推近 / 在虚空里慢慢漂。所有东西都只会淡入淡出 = 不合格。切镜卡在 BGM 拍子上。

## 7. 结尾

一条地平线从左到右点亮 → 地平线下升起**大而亮的太阳**，带一圈放射光线，暖黄光铺满下半屏 → 暖光里出现最后一句大字 → 淡出。
