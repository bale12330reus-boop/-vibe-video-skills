# 科学 × 人生 暗黑剪影：输入主题 → 成片

视觉逆向自叁号暗房三条爆款，画面和字的规则见 `references/风格-暗黑剪影.md`；能直接调用的场景在 `assets/index-模板.html`。文案结构沿用 12 段（见 `examples/熵/逆向分镜.md` 的结构表，那是上一版《熵》的结构拆解，骨架照抄、视觉按新风格重画）。拿不准的时候，照着结构抄，不要自己发明。

## 一句话母提示词（新风格的原始意图）

> 用一个规律，讲一件人人都经历过、但说不清为什么的事。第一帧就砸一句冲突或反常识的话，不铺垫、不讲道理，2 秒后切走；再用三个"不管它就会变坏"的日常画面当证据快闪，然后用一个能数清楚的小模型把规律讲成算术，再一步步从"东西"讲到"你的身体"，再讲到"你的感情"；在最低处翻转——规律有个前提，而你可以打破这个前提；最后用一句金句定格，再把一个选择题抛给观众。全片无旁白，只有字和音乐；画面纯黑，只有一个极小的剪影人物和一条发光的象征物（桥/钟摆/提线/跑道二选一贯穿全片）。

## 视觉铁律（这一版与上一版最大的不同）

1. **纯黑底**：`#000`，不做渐变、不做中心提亮。黑本身就是留白。
2. **人物极小**：剪影/火柴人只占画面 1/10 以下，无面部细节，以姿态传情（跑/弯腰/坐/站）。人物是配角，视觉主角永远是象征物。
3. **一个象征物贯穿全片**：从 `symbridge`（桥）/`pendulum`（钟摆）/`puppets`（提线）/`track`（跑道）/`glowpath`（光轨）里选一个，开场定下来就不再换。换象征物 = 换一条视频。
4. **点缀色按情绪段落切换**：默认荧光白；情绪转折处允许整屏换色（暖红金 → 暗蓝 → 鎏金）。一屏最多点亮 1–2 个词。
5. **四层文字，位置固定**：左上伪搜索框（全片常驻）＋ 中央大字幕 ＋ 右上信息卡（按段落出现）＋ 右上水印（全片常驻）。
6. **镜头几乎不动**：全静态或极缓慢推近（全片不超过 1.05 倍）；场景间硬切，全片 4–6 次，只在小节第一拍。

## 开场铁律：前 2 秒（沿用上一版，比原片优先）

1. **第 0 帧就有完整的字**：不黑屏淡入，不先出片名、系列名、logo，不等音乐前奏，不逐字糊入（模板里 `say()` 加 `instant: true`、`size: "hook"`）。
2. **只有一句，不超过 12 个字**（标点也算），2 秒内读得完。只能是这两种之一：
- **反常识**：和大家以为的正相反，但查得到出处。例：「房间变乱，不是你懒。」「心跳加速，不一定是心动。」
- **冲突**：两样不该放在一起的东西撞在一起。例：「你心动的，可能只是这座桥。」
3. **只下判断，不讲道理**：用陈述句，不解释为什么，不给背景，不出现定律名、科学家、年份。不用「你知道吗」「有没有想过」「今天聊聊」「为什么……？」这种开头。
4. **必须是真的**：钩子里的判断要在 文章.md 里有出处。不准靠把结论说过头来制造反常识（不能写「心跳加速根本不是爱」）。查不到出处就换一句。
5. **画面在第 0 帧就在动，而且已经是"出事之后"**：人物已经在跑/弯腰，象征物已经亮着。不要从空黑屏慢慢长出来。
6. **约 2 秒切走**：在第一个小节线（1.8–2.2 秒之间）硬切到第二刀：加码或悬念，仍然不解释（例：「打扫一万次，它就再乱一万次。」）。这一刀不算进全片 4–6 次硬切。
7. **然后才是证据**：物 → 城 → 感情三个画面各 1 小节快闪，最后砸一个冷色词；接"宇宙级判词"。整段控制在 12 秒以内。

**自检**：截第 0、0.5、1.9 秒三帧。第 0 帧必须能读到完整的钩子；把这三帧给一个不知道主题、听不到音乐的人看，他会想问"为什么？"。做不到就重写钩子，不要往后加铺垫来补救。

## 你从用户那里拿什么

- **必填**：主题。
- **可选**：时长（默认跟 BGM 走，约 2.5–3 分钟）、横竖屏（默认 1920×1080）、象征物（默认按主题从桥/钟摆/提线/跑道/光轨里选一个，也可以用户指定）、要不要片尾的创作者尾声（默认要，但要用户自己的话，见第 2 步）、是否分步确认（默认不分步）。
- **BGM**：在项目文件夹或用户说的位置找音频（mp3/wav/m4a/flac），复制成 `<主题>/bgm.mp3`；多个就问用哪个；**没有就停下来问**。不要自己生成或下载音乐。最好是有一段明显停顿、结尾自然收住的电子/氛围曲。

## 两种模式

- **全自动（默认）**：一口气做到成片。每步做完按 `<check>` 自查，不过就自己改。
- **分步**（用户说"每步停一下"）：在 桥 → 文案 → 分镜 → 10 秒样片 4 处停下等用户点头。

只在这些情况停下来问：没有 BGM；环境装不上；第 0 步找不到像样的"感情"那一层（见下）。

## 第 0 步 · 找桥 → 桥.md（这一步决定视频好不好）

```
<role>你是科普随笔作者，擅长从一个规律里，看见普通人的生活。</role>
<task>围绕写 桥.md，先写开场钩子，再回答 7 个问题，每个一两句：
0. 前 2 秒那一刀：写 3 条候选钩子（每条不超过 12 个字，标明是"反常识"还是"冲突"，写出它靠的是哪条事实），选一条并说理由。规则见上面「开场铁律」。
1. 一句话定律：说的是什么？（小学生能懂的版本）
2. 三个"不管它就会……"的画面：一个"物"、一个"城/群体"、一个"感情"。三个必须是同一个规律，且能用"剪影小人 + 一个发光象征物"画出来（象征物从桥/钟摆/提线/跑道/光轨里选，先定一个，全片不再换）。
3. 玩具模型：一个能数清楚的小模型，能把规律讲成算术（硬币、骰子、排队、存钱）。写出它算出来的那个惊人数字。
4. 一行公式或一个核心数字 + 提出它的人 + 年份 + 一个关于这个人的人情细节（墓碑、信、争论、晚年）。
5. 落到"你的身体"：一个可测的数据（体温、心跳、细胞数）和一句名人原话。
6. 反转点：这个规律成立的前提是什么？人能怎样打破这个前提？
7. 结尾抛给观众的问题：一个选择题或两难（例："你现在是骆驼、狮子，还是孩子？"），再加三件今晚就能做的小事（可选）。
最后给这个桥打分（1–10），说清最弱的一环；钩子单独打分：一个刷到这条视频的陌生人，只看这一句会不会停下来。</task>
<avoid>把比喻说成科学结论（不能说"科学证明感情会变冷"，只能说"感情，也是一样"这种类比）；硬凑感情那一层；玩具模型需要先懂别的知识才能看懂；象征物选两个以上。</avoid>
<check>低于 7 分，或者第 2、6 条想不出来：换一个更贴切的相关规律，把换的理由写清楚；还是不行就停下来问用户。钩子低于 7 分：重写钩子，不准靠后面多铺几句来补。</check>
```

## 第 1 步 · 查证 → 文章.md

```
<role>你是事实核查编辑。</role>
<task>把 桥.md 里每一个数字、年份、人名、原话都上网查一遍，整理成 文章.md，每条后面写出处链接。开场钩子靠的那条事实第一个查；查不实就换成另一条候选钩子。玩具模型里的数字自己算一遍（写出算式）。信息卡里要出现的人名/出处/年代单独列一节「信息卡素材」。</task>
<check>出处优先：百科、原始论文、大学/机构官网、权威媒体。找不到权威出处的删掉，或改成不带数字的说法。名人原话要找到原文（英文就用英文原句核对，中文是你的翻译要标"大意"）。删了什么列在文末「自查删除」。</check>
```

## 第 2 步 · 文案 → 文案.md

```
<role>你是无旁白短片编剧，写的句子像诗但每个字都是大白话。</role>
<context>观众只看屏幕上的字配音乐。全片 80–100 屏，一屏一句，每句不超过 18 个字。按下面 12 段写，每段标出对应的段号和大约秒数（按 BGM 总长折算，比例见 examples/熵/逆向分镜.md 的结构表）。画面只有四层文字：左上伪搜索框（全片同一句，写在文案开头「系列标识」里）、中央大字幕（每屏的句）、右上信息卡（只在有权威引入/引文/年代的段落出现，写出三行内容）、右上水印（创作者名，全片同一句）。</context>
<task>
开头先写「系列标识」：searchbox 文案（主题词 · 人名，例"权力意志 · 尼采"，全片不变）、watermark（创作者名，全片不变）。
① 开场（12 秒以内，照「开场铁律」）：
- 第 1 屏（0–2 秒）：钩子，一句，不超过 12 个字，反常识或冲突，只下判断不讲道理。
- 第 2 屏（约 2–4 秒）：第二刀，加码或悬念，仍不解释。
- 证据快闪：物 → 城 → 感情，每个一屏一句，感情那句停在"就会——"，下一屏只砸一个冷色词。
- 一句判词："是整个宇宙，本来就是这么写的。"（按主题换说法）
② 揭名：概念名 + 一句定律 + 一句去魅（"可是，「乱」并不是一种力。"）
③ 玩具模型：先给"只有 1 种"，再给那个惊人的大数字（整串写出来），再落到"所以随便晃一晃，它几乎一定……"，收在一句拟人。
④ 公式 + 人：公式一屏，每个字母一句话解释，人名 + 年份，人情细节一句。这一段配 infocard（三行：英文名/中文名+生卒年/出处）。
⑤ 回扣开场：用新道理重讲①的物和城，最后一屏"那么问题来了——"
⑥ 转向你：一个问句（"你，为什么还没有乱掉？"）+ 数据 + 原因 + 名人原话 + "一旦停下来——"
⑦ 感情：类比句开头（"感情，也是一样。"），用一段越来越短的聊天记录表现，"没有坏人"的判断，再砸一个冷色词。
⑧ 反转：重复定律原句，圈出前提那个词，一句解释，一句"只要……，就能……"
⑨ 正向排比：①的三个画面倒放回来 + 感情里的三个小动作 + "这些，全部是在 X。"
⑩ 金句 + 提问：金句单独成屏定格（120–160px），然后把一个选择题/两难抛给观众（"你现在是骆驼、狮子，还是孩子？"），不说教、不喊关注。三件今晚就能做的小事可选，要就放在提问之后。
⑪ 片名卡：用钩子或①里某句的前半句 + 省略号（"不清扫，就会……"），下面小字英文名。
⑫ 尾声（可选）：两三行作者自己的话 + 两行金句收束。这段必须来自用户，问用户"做这条视频时你自己有什么感触"；全自动模式下用户没给，就删掉这段，不要替用户编个人经历。
每屏标出要点亮的词：金 = 秩序/能量/你，冷蓝 = 混乱/变冷，赭红 = 警示/欲望。点缀色允许在情绪转折处整段切换（在段首注明）。</task>
<avoid>旁白腔和套话（"你知道吗""让我们""震惊"）；说教（"你应该……"）；文章.md 里没有的事实；一屏两个以上高亮词；比喻说成科学结论；开头先铺背景、先讲定律、先出片名；结尾喊"关注我""点赞收藏"。</avoid>
<check>逐屏数字数；钩子不超过 12 个字、不含定律名和"为什么"；每个事实对得回 文章.md；①的三个画面在⑤和⑨都回来了；⑩的结尾是提问不是说教；从头念一遍，像一个人深夜在跟你说话，而不是课本。</check>
```

## 第 3 步 · 分镜 → 分镜.md

先读节拍：`python scripts/beat.py <主题>-暗黑版/bgm.mp3`，得到 `bpm`、`first_downbeat`、`bar_starts`、每 2 秒响度 `loud_2s_db`。

**BGM 前奏太长就剪掉**：钩子在 0 秒出现，音乐也要在 0 秒就响。如果 `first_downbeat` 超过 0.3 秒，或开头几格 `loud_2s_db` 明显偏弱（比全曲中位数低 10 dB 以上），就从第一个重拍（或第一段够响的小节开头）剪起，加 0.05 秒淡入防爆音，再重跑 beat.py：
`ffmpeg -ss <秒> -i bgm.mp3 -af afade=t=in:d=0.05 -c:a libmp3lame -q:a 2 bgm-cut.mp3`（剪完替换 bgm.mp3，原文件改名留着）。

```
<role>你是动效导演，最在意"一个象征物贯穿全片"和"人物永远很小"。</role>
<task>写 分镜.md。开头写「全片统一规则」（照 references/风格-暗黑剪影.md）：象征物是哪个、点缀色在哪几段切换、searchbox/watermark 文案。然后一张表：镜号 | 时间（小节号 + 秒） | 场景函数（从下面场景库选）| 参数要点 | 字（位置 + 高亮色）| 动作。</task>
<rules>
- 一屏字 ≈ 1 小节（BPM 100–120 时约 2 秒）；两行或超过 12 个字给 2 小节。切换落在小节第一拍。
- 钩子屏：0 秒开始，`instant: true`，`size: "hook"`，居中；画面是"出事之后"的状态并且在动（人物已经在跑/弯腰，象征物已经亮着）；在第一个小节线（1.8–2.2 秒）硬切到第二刀。BPM 太慢、一小节超过 2.2 秒时，切在第 1 小节的第 3 拍。
- searchbox + watermark 从 0 秒到 END 全片常驻（分镜表第一行就写好）。
- infocard 只在④（公式+人）这类有权威引入的段落出现，每次不超过 2 小节。
- 象征物一旦选定全片不再换；同一象征物在不同段落只改参数（颜色/生长进度/摆动幅度）。
- 人物 s 参数永远 ≤ 160（110 最佳）；一屏最多 3 个人物。
- 转场：场景间硬切，全片 4–6 次（2 秒处钩子那一刀不算）；允许极慢推近（用 gsap 对 #stageAll 做 scale 1→1.05，全片只用 1–2 次）；其余用画面内变化（象征物生长、人物姿态、点缀色切换）。
- 第一个"爆点"（响度相邻两格升高 6 dB 以上，或音乐停顿后回来的那一拍）放①结束那句判词，用硬切。另一个爆点放⑩的金句，配白闪。音乐停顿那一段放⑦感情的开头。
- 音乐结束后的安静尾巴放⑪⑫，最后 0.5 秒淡到全黑。
- ①的三个场景在⑤和⑨要用同一个场景函数、同样的参数再出现一次（只改象征物的状态参数）。
</rules>
<scene_library>（都在 assets/index-模板.html 里，参数见函数上方注释）
```

## 踩过的坑

- **开头铺垫**：第一屏必须是钩子，第 0 帧就有字（见「开场铁律」）。BGM 前奏长就剪掉，不要让字等音乐。
- **钩子说过头**：为了反常识把结论说满。钩子也要对得回 文章.md。
- **人物画太大**：剪影超过画面 1/10，"人很小、命题很大"的感觉就没了。`s` 参数 110 最佳，永远不超过 160。
- **象征物换来换去**：一条视频只用一个象征物。想换 = 重做一条。
- **字压在最亮处**：字幕在底部时，发光物主体放在画面中上；字和最亮的发光物不要重叠。
- **伪搜索框太长**：searchbox 文案超过 10 个字会挤，多用"主题词 · 人名"的短格式。
- **信息卡刷屏**：infocard 只在有权威引入的段落出现，每次不超过 2 小节，不要每段都挂。
- **结尾说教**：⑩的结尾是提问不是说教，更不要喊"关注我"。
- **字体没加载就采样**：模板已处理字体加载，不要删 `document.fonts` 那几行。
- **入场没播完就到离场**：`say()` 的入场要在 `t1 - 0.3` 之前播完，否则字会闪回。字多的句子给 2 小节。
- **渲染不确定**：不能用 `Math.random()`、`Date.now()`；所有画布场景只根据时间 `t` 画，随机数用模板里带种子的 `mkRnd()`，在页面加载时就算好。
- **走网络会失败**：GSAP、字体全用本地文件。
- **中文路径**：miniaudio 打不开中文路径，`beat.py` 已改成先读字节；别的工具出错就复制到英文路径再处理。
- **比喻当事实**：「感情会变冷」是类比，文案里用"也是一样""就像"引出，不要写"科学证明"。
- **替用户编尾声**：⑫ 尾声是作者自己的感触，用户没给就删，不要编。
- **忘了出封面**：成片渲完不等于做完。第 5 步的两张封面必须出，并和成片一起发给用户。
