# 风格：暗黑剪影随笔（逆向自叁号暗房三条爆款）

一句话：**纯黑的底上，极小的剪影人物和发光的象征物；白色宋体大字居中，一句里只有一两个词被点亮成颜色。** 没有照片，没有卡通表情，没有复杂运镜。

## 颜色（点缀色按主题/情绪段落切换）

| 用途 | 色值 | 什么时候用 |
|---|---|---|
| 底色 | `#000000` 纯黑 | 全片，不做渐变 |
| 正文字 | `#f2f2f2`，极淡白色光晕 | 全片 |
| 次要字 | `rgba(242,242,242,.55)` | 信息卡、水印、注释 |
| **荧光白 `#ffffff`** | 默认强调、剪影人物本体 | 人物、桥、主要象征物 |
| **赭红 `#c14a2e`** | 警示、欲望、跑道、深渊 | 尼采篇跑道、红崖 |
| **鎏金 `#ffd27a`** | 神圣、真理、文本、奖牌 | 金句、公式、哲学家名 |
| **暗蓝 `#33507a`** | 孤独、夜晚、内省 | 独居、夜晚段落 |
| **冷蓝 `#a9dcff`** | 虚无、变冷、疏远 | 虚无、失去连接 |

一屏最多点亮 1–2 个词；同一个概念全片用同一种颜色；**情绪转折处允许整屏换点缀色**（如年夜饭暖红金 → 独居暗蓝 → 钟摆鎏金）。

## 人物：剪影，不画脸

- 无面部细节的剪影/火柴人，只占画面 **1/10 以下**，以姿态传情：弯腰力竭、奔跑、静坐、站立。
- 本体近白 `#e8e8e8`，带主题点缀色的发光描边（呼吸感：透明度随时间轻微起伏）。
- 人物永远是配角，视觉主角是象征物（桥/钟摆/线）。

## 象征物（每条视频选 1 个，贯穿全片）

桥（跨越/成为）、钟摆（两极摆荡）、提线（被操控）、跑道（前行/力竭）、光丝（连接/断裂）、深渊（回头即沉沦）。
画法：发光线条，横贯画面，线条本身会"生长"（描边动画从 0 到全长）。

## 画面上的文字（四层，位置固定）

1. **左上伪搜索框**：圆角搜索框样式，放大镜图标 ＋ 主题词（如"权力意志 · 尼采"）。全片常驻，是系列最强标识。
2. **中央大字幕**：旁白关键词句，白色宋体，居中。
3. **右上信息卡**：哲学家英文名 ＋ 生卒年，或引文出处（如 `Also sprach Zarathustra`）、年代标注（如 `c. 500–1500`）。按段落出现。
4. **右上水印**：创作者名，恒定，淡色。

## 字

- 主字：思源宋体（Noto Serif SC）Bold/Black。底部字幕 52px；中央句子 64–84px；金句 120–160px 单独成屏。
- 数据/英文：等宽或 Georgia 斜体，鎏金或白色。
- 位置只有 3 种：底部居中字幕（画面主体在上半时）、正中（纯黑底时）、上方（主体在下半时）。
- 断句按语义分行（每行 5–9 字），一次呈现一整句，不做逐词弹出。

## 动作词表（只用这些）

1. **字糊进来**：每个字从「透明 + 模糊 10px + 下沉 10px」到清晰，逐字 0.03–0.05 秒，整句 0.6 秒内出完。离场整句模糊淡出 0.3 秒。
2. **剪影姿态**：跑步的人腿交替、弯腰的人轻微起伏（呼吸感），不做位移。
3. **象征物生长**：桥/线用描边动画从一端长到另一端，1–2 秒。
4. **发光呼吸**：象征物和人物描边的光晕透明度随时间正弦起伏。
5. **极慢推近**：整屏极缓慢放大（全片不超过 1.05 倍），制造呼吸感；或完全静止。
6. **硬切**：场景间硬切，全片 4–6 次，只在小节第一拍。
7. **白闪**：只在最重的拍上，全片 1–2 次。

## 不要做

照片和截图；图标、emoji、有表情的卡通人物；紫色渐变和霓虹；粗描边大色块；复杂运镜（旋转、快速推拉）；一屏两个以上高亮词；画面里同时出现两段不相关的字；字压在最亮的发光物上；人物画得太大（超过画面 1/10 就失去了"人很小、命题很大"的感觉）。
